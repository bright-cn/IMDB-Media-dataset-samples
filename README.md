# IMDB 媒体数据集样本

<h2>包含 1,021 条记录的示例数据集</h2>

<a href="https://www.bright.cn/">
    <img src="https://github.com/bright-cn/IMDB-Media-dataset-samples/blob/main/datasets-image.png" alt="Bright Data 数据集" />

此 **IMDB 媒体数据集样本**包含 **1,021 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `title` | 媒体内容的官方标题。 |
| `popularity` | 衡量内容在 IMDB 平台上的受欢迎程度。 |
| `genres` | 与内容相关的类型列表。 |
| `presentation` | 媒体内容的简要摘要或介绍。 |
| `credit` | 创作者的详细信息，包括导演和编剧。 |
| `videos` | 与该媒体相关的视频内容链接及详细信息。 |
| `photos` | 与该媒体相关的图片内容链接及详细信息。 |
| `top_cast` | 主要演员的信息。 |
| `details_release_date` | 媒体内容的正式发行日期。 |
| `details_countries_of_origin` | 该媒体的制作国家或地区。 |
| `details_official_site` | 媒体内容的官方网站链接。 |
| `details_language` | 媒体内容使用的主要语言。 |
| `details_also_known_as` | 媒体内容的其他标题或名称。 |
| `details_filming_locations` | 媒体的拍摄地点。 |
| `details_production_companies` | 参与媒体制作的公司。 |
| `specs_color` | 媒体色彩规格的信息。 |
| `specs_sound_mix` | 媒体混音规格的详细信息。 |
| `specs_aspect_ratio` | 媒体的宽高比规格。 |
| `url` | 媒体 IMDB 页面对应的 URL 链接。 |
| `comment` | 用户对该媒体的评论或评价。 |
| `media_type` | 媒体内容的类型，例如电影或电视节目。 |
| `imdb_rating` | 媒体在 IMDB 上的平均评分。 |
| `poster_url` | 媒体官方海报图片的 URL。 |
| `imdb_rating_count` | 媒体在 IMDB 上收到的评分数量。 |
| `awards` | 媒体获得的奖项和提名。 |
| `critics_review_count` | 该媒体现有的影评人评论数量。 |
| `review_count` | 该媒体的用户评论总数。 |
| `review_rating` | 用户评论的平均评分。 |
| `featured_review` | 该媒体的精选或重要评论。 |
| `storyline` | 媒体的详细情节或故事线描述。 |
| `boxoffice_budget` | 媒体内容的制作预算。 |
| `id` | 数据集中媒体内容的唯一标识符。 |


## 使用场景

### 1. 电影行业分析
分析电影类型和受欢迎程度随时间变化的趋势，为制作策略和营销活动提供参考。

### 2. 市场研究
使用该数据集研究消费者在媒体消费方面的偏好和行为，为定向广告提供支持。

### 3. 学术研究
提供有关电影制作、发行详情和观众反馈的全面数据，助力媒体研究。



## 文件格式

该数据集提供多种格式：
- **CSV**（此样本中已包含）
- **JSON**
- **NDJSON**
- **JSON Lines**
- **Parquet**
- **压缩格式（.gz）**
